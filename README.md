# Labdhi Mandovara — Inside Sales & Business Development Portfolio

> **"Turning Conversations Into Opportunities."**

An editorial, architectural-grade portfolio designed for **Inside Sales, Business Development, Client Relationships, and Lead Generation** roles. Modeled closely after the high-craft design system of Eemon Roy's portfolio (featured on Wall of Portfolios).

## Positioning & Core Strengths
- **Lead Generation**: Identifying prospects, qualifying leads, and building pipeline.
- **Client Communication**: Active listening, understanding customer needs, and framing ROI.
- **Structured Outreach**: Multi-channel campaigns (3+ technology outreach initiatives at AIESEC, 200+ participant feedback responses analyzed).
- **Relationship Building**: Dependable follow-through, stakeholder empathy, and long-term trust.
- **Pitching & Presentation**: Winner of **Best Pitch** at Social House Learning; Finalist in Nomura KakushIN 10.0 (1,000+ teams).
- **Tech Fluency Edge**: B.Tech background providing domain literacy to bridge technical products and non-technical business buyers.

## Tech Stack
- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + Custom Architectural Grid System
- **Typography**: Averia Serif Libre, Averia Libre, Geist Mono, Inter
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Deployment**: Vercel

## Local Development
```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build

# Preview build
npm run preview
```
